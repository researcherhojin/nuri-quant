# Markdown audit — 2026-10-23

Scope: issue #1929, based on main `4ab35380`. The initial inventory contains
82 project Markdown files: 64 tracked and 18 local-only. This report is an
additional tracked artifact. Dependencies, generated runtime reports, model
transcripts, Git internals and external personal skill installations are excluded.
Local-only notes remain ignored; they are not made public by this audit.

This is a bounded documentation audit, not a claim that every sentence is proved.
All inventory files were scanned for relative file links, explicit repository
paths, Make targets and Python test references. Semantic checks focused on
current commands, CI, configuration, pipeline boundaries, model routing, API
caches and historical/current status. External publications, provider notices,
model prices, old backtests and production health were not remeasured.

## Reference sweep and dispositions

The session-local scanner checked 74 relative file links, 1,153 explicit path
occurrences, 83 Python test-node references and 368 Make-target occurrences
across the original 82 files. File links resolve and the Python nodes exist.
This checks existence, not whether reverting a fix makes its cited test fail;
no mutation-testing claim is made. Link anchors, arbitrary prose symbols and
upstream URLs are not covered by that scanner.

49 reported references are retained with these classifications:

- Generated/private KIS credential and token paths: optional, ignored files;
  absence from a fresh checkout is expected.
- SIEGE audit paths: deleted tools explicitly recoverable at `d8a89ede`.
- Phantom-fix lint and harness-quality-report: explicitly planned, unimplemented.
- Paths/targets in dated audit, plan and handoff archives: historical or proposed;
  the new headers explicitly prohibit treating them as current runbooks.
- `new_agent.py`: a new-file example, not an existing implementation.
- `make verify-*` and `make sync-{start,end,status}`: command-family shorthand,
  not literal missing targets.

Vendor notices were preserved. The shadcn stylesheet SHA-256 matches its notice;
Oxlint pins match package.json. This does not assert a new upstream license audit.
