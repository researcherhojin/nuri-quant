# 디스코드 thesis 읽기

*English (official) edition: [../THESIS_DISCORD.md](../THESIS_DISCORD.md)*

`/thesis ticker:<TICKER>` 는 탐색용 로컬 분석을 시작한다. 주문을 내거나
파일럿 원장에 채점 표본을 추가하지 않는다.

스레드에는 한 자리에서 갱신되는 진행 상태표와 최종 결과가 나온다.
단계 완료는 검증된 형식의 출력이 반환됐다는 뜻이다. 근거의 정확성이나
모델의 투자 성과를 증명하지 않는다. “근거 없음”은 해당 단계에 근거가
부족했다는 뜻이고, “미확인”은 봇이 종료 이벤트를 관측하지 못했다는 뜻이다.
어느 쪽도 조용히 완료로 처리하지 않는다.

최종 결과는 실행 상태와 모델 등급을 구분한다. Buy / Overweight / Hold /
Underweight / Sell 은 모델의 분석 등급이며 주문 지시나 보유 비중이 아니다.
Hold 는 중립 또는 **근거 부족**일 수 있다. REVIEW 는 유효한 판정을
확정하지 못했다는 뜻이다. 실행이 끝나도 누락된 단계가 있으면 검토해야 한다.
등급이 있다는 이유만으로 결과 카드를 초록색으로 표시하지 않는다.

## 저장된 근거 열기

최종 카드의 명령을 복사해 실제 분석이 실행된 단말의 저장소에서 실행한다.
기본 원격 대화형 경로는 운영 파일럿 모델 호스트가 아닌 개발 단말에서 실행된다.

```bash
uv run python -m nuri.agents.discord.thesis_report --ticker DEMO --run aaaaaaaaaaaaaaaa --open
```

예시 종목과 실행 ID를 카드에 표시된 값으로 바꾼다. 설정된 `archive_dir/runs`
아래의 정확한 JSON 기록을 읽고 같은 디렉터리에 비공개 HTML 파일을 생성한다.
가격 갱신, 모델 호출, JSON 원본 수정, 원장 쓰기는 수행하지 않는다.
`--open` 을 생략하면 생성된 파일 경로를 출력한다. 원본이 없거나 전체 해시가
일치하지 않으면 종료 코드 2로 실패한다.

로컬 화면에는 저장된 판정 근거, 강세·약세 주장, 단계 누락, 상세 보고서,
입력 기준 시점과 관측 시간이 나온다. 누락된 정보는 명시하며 최신 자료로
과거 기록을 재구성하지 않는다. 텍스트는 이스케이프하고 외부 리소스나 스크립트를 쓰지 않는다.

원문에는 비공개 맥락이 포함될 수 있다. 분석 실행 단말에 보관하며 디스코드에
첨부하지 않는다. HTML을 공개 채널에 업로드하지 않는다. 디스코드 카드에는
허용 목록에 있는 상태·등급·실행 ID만 담는다.
